# MERN Full Stack Development 📚

Welcome to my **MERN Full Stack Development** repository!

This repository contains class teaching materials, lecture notes, code examples, and practice programs covered during my MERN Stack development classes. It serves as a central place to organize concepts and revise topics throughout the course.

## 🛠️ Technologies Covered

- **HTML5** – Web page structure
- **CSS3** – Styling and layouts
- **JavaScript** – Programming fundamentals and DOM manipulation
- **React.js** – Frontend development
- **Node.js** – Server-side JavaScript
- **Express.js** – Backend development and REST APIs
- **MongoDB** – Database management
